# 🔮 크리스탈 볼 비디오 인코더

3D 크리스탈 볼 비디오 플레이어(480×480 원형 LCD)에서 바로 재생되는 포맷으로
영상을 변환해주는 **설치 없는 웹앱**입니다. 스마트폰/PC 브라우저에서 영상을
선택하면 기기 안에서 바로 인코딩됩니다. **서버 업로드 없음 = 무료 · 빠른 시작 · 프라이버시 보장.**

## 전략: 왜 "웹앱 + 브라우저 내 인코딩"인가

| 선택지 | 장점 | 단점 | 판정 |
|---|---|---|---|
| **정적 웹앱 (ffmpeg.wasm)** ✅ | 설치 불필요, iOS/Android/PC 모두 동작, 호스팅 무료(GitHub Pages), 서버 비용 0, 영상이 기기를 떠나지 않음 | 인코딩 속도가 네이티브보다 느림, 브라우저 메모리 한계(대용량 파일) | **채택** |
| 네이티브 앱 (Android/iOS) | 인코딩 빠름(HW 가속) | 두 플랫폼 각각 개발, 스토어 심사·배포 비용, 업데이트 느림 | 2단계 확장 후보 |
| PC 프로그램 | 빠르고 안정적 | "스마트폰에서 넣으면"이라는 핵심 요구와 불일치 | 보류 |
| 서버 인코딩 웹서비스 | 기기 성능 무관 | 서버 비용, 업로드 대기, 프라이버시 우려 | 보류 |

크리스탈 볼용 영상은 대부분 **짧은 루프 영상(수십 초~수 분)** 이므로,
브라우저 내 인코딩의 속도·메모리 한계가 실사용에서 문제되지 않습니다.
이 판단이 웹앱 채택의 핵심 근거입니다.

## 출력 사양 (기기 요구사항에 고정)

| 항목 | 값 |
|---|---|
| 해상도 | 480 × 480 (1:1) |
| 비디오 코덱 | H.264 (AVC) Main Profile, Level 3.1, yuv420p |
| 오디오 코덱 | AAC 또는 MP3, 44,100 Hz, 128 kbps |
| 프레임 레이트 | 30fps 기본 (25/24 선택 가능, 60fps 미제공 — 기기 버퍼링 방지) |
| 비디오 비트레이트 | 2,000 ~ 4,000 kbps (기본 2,500) |
| 컨테이너 | MP4, `+faststart` |

## 주요 기능

- 📁 드래그앤드롭 / 탭 한 번으로 영상 선택 (MP4·MOV·MKV·WEBM·AVI 등)
- 🔲 화면 맞춤 3모드: **중앙 크롭**(권장) / 전체 표시(레터박스) / 늘리기
- ⭕ **원형 표시 영역 미리보기** — 크리스탈 볼에서 실제로 보이는 원형 범위 확인
- 🎚️ 비트레이트·fps·오디오(AAC/MP3/무음) 선택, 예상 출력 크기 표시
- 📊 실시간 진행률 + 취소 + 상세 ffmpeg 로그
- ⬇️ 완료 후 미리보기 & 한 번에 저장 (`원본이름_480x480.mp4`)

## 기술 구조

```
index.html / style.css / app.js   ← 순수 정적 파일 (빌드 도구 없음)
vendor/ffmpeg/                    ← ffmpeg.wasm 셀프호스팅 (CDN 미의존)
  ffmpeg.js, 814.ffmpeg.js        ← @ffmpeg/ffmpeg 0.12.10 (UMD + 워커 청크)
  util.js                         ← @ffmpeg/util 0.12.1
  ffmpeg-core.js, ffmpeg-core.wasm← @ffmpeg/core 0.12.6 (싱글스레드, 약 32MB)
```

- **싱글스레드 코어**를 쓰는 이유: 멀티스레드 코어는 `SharedArrayBuffer`가 필요해
  COOP/COEP 헤더를 요구하는데, GitHub Pages 등 정적 호스팅에서는 설정할 수 없습니다.
  싱글스레드는 어디서나 동작합니다.
- **셀프호스팅**하는 이유: CDN에서 로드하면 워커의 same-origin 제약과 CORS 문제가
  생깁니다. 저장소에 포함하면 오프라인 캐시도 가능해집니다.
- 인코딩 명령 요약:
  `-vf scale=480:480:...(crop|pad),fps=30,format=yuv420p -c:v libx264 -profile:v main -level 3.1 -b:v 2500k -maxrate ... -movflags +faststart -c:a aac -ar 44100`

## 배포 (GitHub Pages)

`.github/workflows/deploy-pages.yml`이 푸시할 때마다 자동 배포합니다.
저장소 **Settings → Pages → Source**를 **"GitHub Actions"** 로 한 번만 설정하면
`https://<계정>.github.io/<저장소>/` 에서 바로 사용할 수 있습니다.

로컬 테스트: `python3 -m http.server 8000` 후 `http://localhost:8000` 접속.
(`file://`로 직접 열면 워커/fetch가 막혀 동작하지 않습니다.)

## 알려진 한계

- 휴대폰에서 인코딩 속도는 실시간의 약 0.3~1배 (3분 영상 → 수 분 소요)
- 브라우저 메모리 한계상 대용량(500MB+)·장시간(10분+) 영상은 실패 가능 → PC 브라우저 권장
- iOS는 Safari 16.4 이상 필요

## 로드맵 (다음 단계)

1. **PWA화** — 홈 화면 추가 + 오프라인 동작 (manifest + service worker)
2. **WebCodecs 가속** — 지원 브라우저에서 HW 인코더 사용, 속도 5~10배 개선
3. 구간 자르기(트리밍) / 여러 파일 일괄 변환
4. 필요 시 네이티브 앱(Capacitor로 웹 코드 재사용) 검토

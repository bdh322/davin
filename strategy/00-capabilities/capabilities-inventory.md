## 1. 분류법 A — 자산 유형
| 유형 | 역량 | 비고 |
|---|---|---|
| 기술·장비 노하우 | CAP-01, CAP-07 | 장비 + 운용 지식. 렌탈·구축 용역·장비 패키지로 판매 가능 |
| 소프트웨어·IP | CAP-02, CAP-04, CAP-05 | 반복 매출(SaaS·라이선스)로 전환되기 가장 쉬운 자산 |
| 운영·서비스 | CAP-03, CAP-06 | 공간·행사를 "굴리는" 능력. 운영 수수료·위탁운영 모델 |
| 크리에이티브·제작 | CAP-08, CAP-09 | 범용·경쟁 심함. 다른 역량의 "연료" 역할 |
| 인력·조직 | CAP-10 | 병목. 채널 파트너(매체사·대행사)로 보완 필요 |

## 2. 분류법 B — 가치사슬 단계 (어느 단계에서 돈을 받을 수 있나)
| 단계 | 역량 | 대표 과금 형태 |
|---|---|---|
| 기획·브랜딩 | CAP-03, CAP-06, CAP-08 | 기획비·컨설팅 |
| 제작 | CAP-05, CAP-08, CAP-09 | 제작 용역 |
| 구축·설치 | CAP-01, CAP-07, CAP-03 | 시스템 구축비·장비 판매·렌탈 |
| 운용·운영 | CAP-02, CAP-03, CAP-06, CAP-07 | 운영 수수료·유지보수·구독 |
| 판매·마케팅 | CAP-10 | (약함) → 파트너십으로 보완 |
핵심: 우리는 **4단계(운영)까지 전부 수행 가능**하다. 대부분의 프로젝션맵핑 경쟁사는 제작·설치에서 끝난다. 운영 단계 역량이 반복 매출의 입구다.

## 7.5 협 답변 반영 (2026-10-01)
- 매출 95%가 전시·시공(미디어)이고 **수익이 나지 않는다** → 피벗 긴급도 높음. 운영 단계(해외 전시관)도 적자 → "시공 수익, 운영 적자"는 동종업계(디스트릭트·닷밀) 패턴과 동일. 해법은 운영을 직영하지 않고 **파트너 자본+라이선스/로열티**로 바꾸는 것(PEER 패턴 2·3).
- 개발 2명(협 포함) → 플랫폼을 처음부터 만들 여력 없음. **기존 CMS/BMS(TouchDesigner 구성형)를 참여 엔진의 뼈대로 재사용**하고, 백엔드는 관리형(Supabase 서울/Cloudflare), 폰 UI는 템플릿 4종 이내로 시작.
- 매체 대행 불가, 기술·콘텐츠 벤더 → 수익모델은 BM-01(매체사 SaaS)·BM-06(공익 구좌 운영)·BM-02(대행사 경유 캠페인). BM-03 레브쉐어는 매체사가 판매하고 우리는 엔진·측정만.
- "하나의 콘텐츠를 여러 곳에" = **템플릿 커스텀** → 제품 단위는 '템플릿 라이선스(구좌당·기간당) + 스킨 커스텀 비용'.
- 레이저챔버는 영구 설치처가 없는 **미출시 연출 상품** → 레이빙 페스티벌·야간관광·행사 렌탈로 먼저 노출(CMB-04).

## 8. 1차 결론 (H:)
1. 반복 매출로 가장 빨리 바뀌는 자산은 **CMB-01(참여형 플랫폼)**, **CMB-05(운영 대행)**, **CMB-04(레이저 상품화)** 순이다.
2. CAP-08/09(제작·촬영)는 단독 상품이 아니라 위 플랫폼·IP의 **콘텐츠 공급 라인**으로 쓴다.
3. CAP-10(마케팅 2명)으로는 직판이 어렵다. **매체사·대행사·공연 프로덕션을 채널 파트너**로 삼는 구조가 전제다.

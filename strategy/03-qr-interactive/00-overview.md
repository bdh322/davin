# QR 참여형 스크린 콘텐츠 — 한 장 요약·가설·포지셔닝

> 상태: 초안(리서치 8트랙 1차 반영) · 최종수정 2026-10-01
> 이 문서는 `03-qr-interactive` 폴더의 입구다. 세부는 각 문서로, 결정은 `91-decisions`, 질문은 `90-questions`.

## 1. 가설 (협의 원안)
기존 미디어 구좌(LED 사이니지·대형 파사드·지하철 DID 등)에 우리가 콘텐츠를 넣되, 구석에 QR을 두어 관객이 스마트폰으로 참여하게 한다. 이를 '미디어아트'가 아니라 **미디어 콘텐츠 산업**으로 보고, 같은 콘텐츠·플랫폼을 여러 곳에 팔아 **캐시카우**를 만든다.

## 3. 포지셔닝 (H:)
**"구좌의 CPM을 올리는 참여 로그 + 공익·팬덤·행사 콘텐츠를 돌리는 운영 엔진"**을 매체사·협의회·구단에 **월정액/시즌 라이선스**로 판다. 브랜드 캠페인은 레퍼런스·현금용, 팬덤 셀프서브는 롱테일, 해외는 화이트라벨.
- 우리가 파는 것: ① 엔진(투표·이모지·캔버스·게임·메시지월·라이트쇼 템플릿 + 스킨) ② 운영(모더레이션·피크 대응·법규 템플릿·현장) ③ 측정(스캔→참여→완료→재참여 퍼널 리포트) ④ 쇼컨트롤 연동(미디어서버·레이저·조명 — 플랫폼 사업자가 못 따라오는 부분).
- 우리가 팔지 않는 것: QR 코드 자체, 범용 사이니지 CMS, 직영 venue.

## 4. 제품 구조 (ARCH ↔ FMT ↔ BM)
```
[콘텐츠 팩: 시즌·공익·팬덤·행사·브랜드 스킨]   ← CAP-08/09 제작 라인
        │
[참여 엔진: 룸/집계/레이트리밋/모더레이션 큐/분석]  ← CMB-01 (CAP-02+04+05)
        │                    │                     │
  (a) 플레이어 HTML5    (b) 이벤트 렌더박스     (c) 미디어서버·레이저 통합  ← CAP-01/07
   매체사 SaaS(BM-01)    브랜드 캠페인(BM-02)    공연·경기장 라이선스(BM-03)
   공익 구좌 운영(BM-06)  팬덤 셀프서브(BM-07)   해외 화이트라벨(BM-05)
```
포맷 사다리: 암묵 반응 → 탭 1회(투표·이모지·라이트쇼) → 그룹 미니게임 → 사전검수형 팬덤 메시지 → [2단계] 자유 텍스트·셀피·생성 AI. (`03-content-formats.md`)

## 5. 캐시카우 경로 (H:, `05-business-model.md` §6)
1. **0~6개월**: 브랜드 캠페인 2~3건 + 공익 구좌 1곳(2기 협의회 또는 지자체 축제) → 사례·측정 데이터·운영 매뉴얼.
2. **6~18개월**: 매체사 SaaS 5~20 스크린 + 스폰서 슬롯(매 주말 돌아가는 참여 슬롯) + 팬덤 셀프서브(대행사·자동심의 제휴).
3. **18개월+**: 데이터 상품 + 해외 화이트라벨(동남아·중동 매체사, 협의 해외 전시관 네트워크) + 경기장·아레나(서울아레나 2027).
목표 KPI: 구좌당 MRR, 스폰서 슬롯 갱신율, 참여 퍼널, 모더레이션 비용/건.
